# What this repo is

- Standalone PHP microframework. It is a library, not an app.
- Namespace is `SeedPHP`, not `Seed`.
- Class chain: `SeedPHP\App` extends `Core` extends `Router`.
- `App::getInstance()` is the singleton entrypoint.
- Composer package `rogeriotaques/seed-php`. Latest tag is `1.9.x`.
- `index.php` is a demo/sample app. It is not the library.
